% Speaking notes
% We replace one label per input with a count vector. Each entry counts the number of labels assigned to one class.
% The network still supplies the concentration parameters of a Dirichlet distribution over possible class probabilities.
% Given one shared probability vector, the repeated labels are independent. Their counts follow a multinomial distribution.
% We marginalise that vector to obtain a Dirichlet multinomial probability for the observed counts.
% Count vectors from different inputs are independent given the inputs and weights, so their probabilities multiply into the likelihood.
% The model retains its weight posterior and Gamma prior. We now ask what the count likelihood adds.
\begin{frame}{Dirichlet Multinomial Evidential BNN (DM-eBNN)}
\label{frm:count-model}
\setlength{\abovedisplayskip}{4pt}
\setlength{\belowdisplayskip}{4pt}
\begin{itemize}
\setlength{\itemsep}{6mm}
\item \textbf{Repeated labels} per input give counts $n=(n_1,\ldots,n_C) %gives counts per class, which is the number of labels observed per class. And n is the count vector.
$, with $R=\sum_c n_c$.
\item \textbf{Network outputs} $\alpha(x;w)=e(x;w)+1$.
% Thesis eq:dm-ebnn-observation.
\begin{align*}
p(\pi\mid x,w)&=\mathrm{Dir}\bigl(\pi\mid\alpha(x;w)\bigr),\\[1mm]
p(n\mid\pi,R)&=\mathrm{Mult}(n\mid R,\pi). %“Instead of modelling one label, we model the class counts from repeated labels. Given the shared class probabilities, these counts follow a multinomial distribution.”
\end{align*}
\item Marginalising $\pi$ gives observation model $p(n\mid x,w)=\mathrm{DM}\bigl(n\mid R,\alpha(x;w)\bigr)$.
\item For count data $D_{\mathrm{count}}=\{(x_i,n_i)\}_{i=1}^{N}$, the \textbf{likelihood} is
% Thesis eq:dm-ebnn-dataset-likelihood, with conditionally independent count vectors given inputs and weights.
\[
p(D_{\mathrm{count}}\mid w)
=\prod_{i=1}^{N}p(n_i\mid x_i,w)
=\prod_{i=1}^{N}\mathrm{DM}\bigl(n_i\mid R_i,\alpha(x_i;w)\bigr).
\]
\end{itemize}
\end{frame}


% Speaking notes
% The likelihood multiplies the probabilities of the observed count vectors across inputs.
% We write each concentration vector as its total concentration multiplied by its mean vector.
% Expanding the Dirichlet multinomial shows how total concentration enters separately from the mean.
% For one label, the Gamma ratios simplify to the corresponding mean probability. With repeated labels, this invariance no longer holds.
% We hold the mean vectors fixed throughout this comparison.
% We ask the same question as for single labels, keeping the mean fixed and changing total concentration.
% The left curve uses one label and remains flat. The right curve uses all fifty-one labels for the same image.

% The compact summary groups other labels only for display. The calculation uses every class count separately.
% Reference only. Image 6505. Class order is airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck.

% The observed counts give higher likelihoods to some total concentrations than others.
% That is what we mean when we say that count data can inform total concentration.
% Total concentration controls the aleatoric and distributional split at fixed means, so the counts can inform that split.
% This example is selected to show an interior maximum. Other count vectors can favour a boundary instead.
% The plot is a controlled likelihood comparison, not a posterior or a concentration selected by training.
% The count probability is small because it concerns this exact count vector. Its axis uses units of ten to the minus seven.
% The Gamma prior remains. Data information does not remove the influence of assumptions.
\begin{frame}{Repeated Labels Can Inform Total Concentration}
\label{frm:count-concentration-information}
\setlength{\abovedisplayskip}{3pt}
\setlength{\belowdisplayskip}{3pt}
\begin{itemize}
\setlength{\itemsep}{5mm}
\item Count likelihood \textbf{depends on total concentration}, % at fixed mean vectors
% “Even at fixed mean vectors, changing total concentration changes the likelihood of the observed counts. Some values of total concentration explain these counts better than others. The count data can therefore inform total concentration.”
{\small
\[
\begin{aligned}
p(D_{\mathrm{count}}\mid w)
% &=\prod_{i=1}^{N}\mathrm{DM}\bigl(n_i\mid R_i,\alpha_0(x_i;w)\,m(x_i;w)\bigr)\\[2mm]
&=\prod_{i=1}^{N}\left[
\frac{R_i!}{\prod_{c=1}^{C}n_{ic}!}\,
\frac{\Gamma\bigl(\alpha_0(x_i;w)\bigr)}{\Gamma\bigl(\alpha_0(x_i;w)+R_i\bigr)}
\prod_{c=1}^{C}
\frac{\Gamma\bigl(\alpha_0(x_i;w)m_c(x_i;w)+n_{ic}\bigr)}
{\Gamma\bigl(\alpha_0(x_i;w)m_c(x_i;w)\bigr)}
\right].
\end{aligned}
\]
}
\item Likelihood \textbf{can inform total concentration} because
observed counts provide evidence favouring some total concentrations over others,
at fixed mean vectors.
\begin{itemize}
\item Count data can therefore inform aleatoric–distributional allocation.
\end{itemize}
\end{itemize}
