% Speaking notes
% The first question concerns our choice of the evidential parameterisation.
% Adding one to positive evidence restricts every concentration parameter to values above one.
% We could instead predict positive concentrations directly and compare the resulting allocation and predictive fit.
% This would remove the restriction from the unit baseline, but would not retain its original nonnegative evidence interpretation.
% We have not tested whether this change improves the model.
% The thesis also leaves the interpretation and practical value of the uncertainty terms open.
% Simulated data with known label variation could test their interpretation. Decision tasks could test whether the terms support better decisions.
% We use one SGLD chain per run. Multiple chains, longer sampling and alternative samplers could assess sensitivity to posterior approximation.
% The repeated label experiments cover CIFAR-10H only. Further datasets would test how broadly the count prediction benefit holds.
\begin{frame}{Limitations and Future Work}
\label{frm:limitations}
\begin{itemize}
\setlength{\itemsep}{4mm}
\item \textbf{EDL restricts concentrations to $\alpha_c(x;w)>1$.}
\begin{itemize}
\item Test direct positive concentrations, $\alpha_c(x;w)>0$.
\end{itemize}
\item \textbf{Practical value of uncertainty decomposition remains untested.}
\begin{itemize}
\item Test whether the separate uncertainty terms improve decisions.
\end{itemize}
\item \textbf{Training setup}
\begin{itemize}
\item Multiple chains, larger sampling budgets, learning rate schedules and alternative samplers.
\end{itemize}
\item \textbf{Repeated label experiments cover only CIFAR-10H.}
\begin{itemize}
\item Obtain and evaluate further datasets with repeated labels.
\end{itemize}
\end{itemize}
\end{frame}
