\item Despite strong performance, their predictions can be overconfident.
\item Estimating uncertainty in a model’s predictions can support safer decisions.

\item Especially important when errors have serious consequences.
\begin{itemize}

% In uncertainty-aware classification, we want a predicted class label and an expression of uncertainty about that label.
% The model assigns probabilities to the possible class labels.

\begin{frame}[t]{Uncertainty-Aware Classification}
\label{frm:classification-uncertainty}
\begin{itemize}
\setlength{\itemsep}{3mm}
\item For a classification task, a neural network outputs probabilities for each class label.
\end{itemize}
\vspace{1mm}
{\centering
\input{figures/cifar_ambiguous_prediction}\par}
\begin{itemize}
    \vspace{1mm}
\item \emph{Predictive uncertainty} quantifies uncertainty about the class label of an input.
\begin{itemize}
\vspace{1mm}
\item Does not by itself guide decisions about how to act.
\item Where does the predictive uncertainty come from?
\end{itemize}
\end{itemize}

% Speaking notes
% Different uncertainty terms can call for different responses.
% Aleatoric uncertainty remains even with known class probabilities, as in the fifty-fifty example.
% More training data cannot remove it when the input information and label process stay the same.
% We may defer a decision if its risk is too high.
% Epistemic uncertainty concerns the network weights. More relevant training examples can help constrain them.
% Distributional uncertainty concerns class probabilities at given weights.
% Malinin and Gales motivate this term through differences between training and test distributions.
% In that setting, collecting examples from the unfamiliar distribution may help.
% Our displayed decomposition does not establish that this image is unfamiliar or validate a particular response.
% These examples motivate representing the three terms together.
\begin{frame}{Decomposing Predictive Uncertainty}
\label{frm:classification-motivation}
{\centering
\input{figures/cifar_ambiguous_decomposition}\par}
\vspace{2mm}
\begin{itemize}
\setlength{\itemsep}{2mm}
\item \textbf{Aleatoric (data) uncertainty} irreducible uncertainty from complexity in the data.
% is the uncertainty that remains even when the class probabilities are known.
\par
\begin{itemize}
\setlength{\itemsep}{0pt}
\setlength{\topsep}{0pt}
\setlength{\partopsep}{0pt}
\item Defer the decision if high risk.
\end{itemize}
\item \textbf{Epistemic (model) uncertainty} reducible uncertainty in the estimated network weights. %(Given the training data. Can be reduced by collecting more data.)
\par
\begin{itemize}
\setlength{\itemsep}{0pt}
\setlength{\topsep}{0pt}
\setlength{\partopsep}{0pt}
\item Collect more relevant training examples.
\end{itemize}
\item \textbf{Distributional uncertainty} is uncertainty about the class probabilities at fixed network weights. % concerns class probabilities at fixed network weights.
\par
\begin{itemize}
\setlength{\itemsep}{0pt}
\setlength{\topsep}{0pt}
\setlength{\partopsep}{0pt}
\item If inputs differ from training data, collect representative training examples. % can quote malin gales here
\end{itemize}
\item \textbf{Different uncertainty terms require different actions.}
\end{itemize}
\end{frame}

% Speaking notes
% We have introduced three uncertainty terms. Which terms do existing approaches represent?
% A normal classification neural network represents only aleatoric uncertainty through the class probabilities that it outputs.
% A categorical Bayesian neural network represents aleatoric and epistemic uncertainty through a posterior over network weights.
% A deterministic Dirichlet network represents aleatoric and distributional uncertainty through a distribution over class probabilities.
% It uses one estimate of the network weights, so it does not represent epistemic uncertainty.
% These representations are complementary. Can we combine them to represent all three terms?
\begin{frame}{Models for Uncertainty Quantification}
\label{frm:model-components}
\begin{itemize}
\setlength{\itemsep}{6mm}
\item \textbf{Bayesian neural networks}
\begin{itemize}
\item Model uncertainty over network weights.    
\item Aleatoric and epistemic uncertainty. %Separate predictive uncertainty into aleatoric and epistemic terms.
\end{itemize}
\item \textbf{Deterministic Dirichlet networks}
\begin{itemize}
\item Model a distribution over class probabilities %, using one set of network weights.
\item Aleatoric and distributional uncertainty.
\end{itemize}
\item  Neither decomposes into all three uncertainty terms.
\end{itemize}
\end{frame}

% Speaking notes
% We combine a Bayesian posterior distribution over network weights with a Dirichlet network that predicts a distribution over class probabilities.
% This lets us represent aleatoric, distributional, and epistemic uncertainty together.
% Representing three terms is only the first step. We also ask what the data tell us about them.
% We study how observed labels and model assumptions shape the allocation between these terms.
% The thesis studies representation and allocation. It does not demonstrate improved decisions, and it does not study descision making at all!.
% We next introduce the background needed to explain the models.
\begin{frame}{Research Aim and Approach}
\label{frm:research-aim}
\begin{itemize}
\setlength{\itemsep}{8mm}
\item Model that represents aleatoric, distributional, and epistemic uncertainty. 
\begin{itemize}
\item Combine Bayesian posterior distribution over network weights with a Dirichlet distribution over class probabilities.
\end{itemize}
\item Understand how the resulting predictive uncertainty is divided between the three uncertainty terms. % what parts of the decomposition is informed by the observed labels and what part reflects model assumptions.
\end{itemize}
\end{frame}
