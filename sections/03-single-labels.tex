\section{Categorical Evidential Bayesian Neural Network}

% Source. Methods 4.3.1, eq:ebnn-hierarchy, eq:ebnn-categorical,
% eq:edl-bnn-full-likelihood. Sensoy et al. 2018, Section 3, pp. 3--4, for the EDL interpretation.
% Speaking notes
% We now combine the two model structures, starting with one observed label per input.
% For a given input and set of weights, the network outputs concentration parameters through the evidence parameterisation.
% We adopt EDL's interpretation of nonnegative network outputs as support for each class.
% Adding one gives a uniform Dirichlet baseline at zero evidence.
% The evidence and baseline then correspond to assigned and unassigned belief in its subjective logic interpretation.
% This is a modelling choice, not a requirement for the uncertainty decomposition.
% Our softplus implementation approaches zero evidence only as a limit.
% These define a Dirichlet distribution over class probabilities. Given those probabilities, the label follows a categorical distribution.
% Marginalising the class-probability vector gives the predicted label probabilities, equal to the Dirichlet mean.
% For each training example, we take the probability assigned to its observed label.
% That is the entry of the mean vector corresponding to the observed class. [m_{y_i}(x_i;w)]
% Given the inputs and shared weights, we assume the labels are independent.
% Knowing one example's label then gives no further information about another example's label.
% We multiply the observed-label probabilities across training examples to obtain the likelihood.
% This likelihood assigns a probability to all observed labels for a given set of weights.
% Next, we examine what it can tell us about the concentration parameters. The prior and posterior follow after that.
\begin{frame}{Categorical Evidential Bayesian Neural Network}
\label{frm:cat-ebnn}
\label{frm:cat-ebnn-setup}
\setlength{\abovedisplayskip}{4pt}
\setlength{\belowdisplayskip}{4pt}
\begin{itemize}
\setlength{\itemsep}{5mm}
\item \textbf{One observed label} per input.
\item \textbf{Network outputs} $\alpha(x;w)=e(x;w)+1$, %concentration parameters
% Thesis eq:ebnn-hierarchy and eq:ebnn-categorical.
\begin{align*}
p(\pi\mid x,w)&=\mathrm{Dir}\bigl(\pi\mid\alpha(x;w)\bigr),\\[1mm]
p(y\mid\pi)&=\mathrm{Cat}(y\mid\pi).
\end{align*}
\item Marginalising $\pi$ gives observation model $p(y\mid x,w)=m_y(x;w)$.
\item Assuming conditionally independent labels, \textbf{likelihood} is% Thesis eq:edl-bnn-full-likelihood.
\[
p(D\mid w)=\prod_{i=1}^{N}p(y_i\mid x_i,w)=\prod_{i=1}^{N}m_{y_i}(x_i;w).
\]
\end{itemize}
\end{frame}

% Speaking notes
% We now ask what the observed labels tell us about the total concentration.
% We hold the mean vector fixed and compare different values of total concentration.
% The likelihood measures how well each value explains the observed labels. The labels prefer values with a higher likelihood.
% In the posterior, the likelihood ratio multiplies the prior ratio. If the likelihood is the same for every value, the labels prefer none of them.
% Then the labels do not inform total concentration, and the prior ratio stays as it is.
% For single labels, each likelihood factor is the concentration of the observed class divided by the total concentration.
% This ratio is the mean probability of the observed class.
% If we scale all concentration parameters at an input by the same number, that number cancels in the ratio.
% So the likelihood does not change with total concentration.
% Here is one factor of this product for a real test image. It shows a deer, and its CIFAR-10 label is deer.
% We fix the mean vector at one weight sample of our trained model. It gives deer a probability of 0.78.
% The axis starts at the smallest total concentration the network can produce with this mean vector.
% Every concentration parameter is above one, so the smallest class probability sets this limit.
% The plot shows the likelihood of the label. It is 0.78 for every total concentration.
% The line is flat, so every value is equally preferred.
% The label prefers no value of total concentration, so it cannot inform it.
% The labels do inform the mean vectors, because the likelihood changes with them.
% This holds at fixed mean vectors. In training, total concentration can still change through the shared weights.
% Next, we see why this matters for the uncertainty allocation.
\begin{frame}{Single Labels Cannot Inform Total Concentration}
\label{frm:likelihood-limit}
\setlength{\abovedisplayskip}{2pt}
\setlength{\belowdisplayskip}{2pt}
\begin{itemize}
\setlength{\itemsep}{5mm}
\item Single label likelihood \textbf{depends only on mean vector},
% Since likelihood depends only on the ratio of concentrations to total concentration the model can learn the proportions a/a_0 but it cannot learn the total concentration.
% Thesis eq:edl-bnn-full-likelihood with eq:general-dirichlet-mean substituted.
\[
p(D\mid w)=\prod_{i=1}^{N}m_{y_i}(x_i;w)=\prod_{i=1}^{N}\frac{\alpha_{y_i}(x_i;w)}{\alpha_0(x_i;w)}
.
\]
\item Likelihood \textbf{does not inform total concentration} because
observed labels provide no evidence favouring one concentration over another,
at fixed mean vectors.
% meaning that there is not some concentrations that give higher likelihoods than others.

% Speaking notes
% We use natural logarithms, so these values are measured in nats.
% The single label likelihood gives no preference between concentrations at the same mean. Why does this matter?
% Concentration changes how predictive uncertainty is divided into aleatoric and distributional uncertainty.
% The total predictive uncertainty stays unchanged because the mean class probabilities stay unchanged.
% We illustrate this with two classes, each with mean probability one half. This is a mathematical example, not an experimental result.
% The dashed line shows the unchanged predictive entropy.
% As concentration increases, the blue aleatoric curve rises and the orange distributional curve falls.
% At every concentration, these two values add up to the dashed line.
% At the left limit, class-probability vectors concentrate near the simplex vertices.
% Knowing the class probabilities then almost determines the label. Aleatoric uncertainty tends to zero.
% At the right limit, class-probability vectors concentrate at the mean.
% Knowing them adds no information beyond the mean. Distributional uncertainty tends to zero and all uncertainty is aleatoric.
% These are limits of the general Dirichlet family. Our EDL parameterisation only uses total concentrations above two for this mean.
% The monotonic relationship still holds within that allowed range.
% This comparison concerns the conditional Dirichlet distribution, not a change in the weight posterior.
% Single labels cannot distinguish these uncertainty allocations at fixed means.
% We therefore state an explicit concentration assumption through the prior.

% Speaking notes
% We return to what single labels can tell us, regardless of the evidence parameterisation.
% At fixed mean vectors, the likelihood cannot distinguish total concentrations or their uncertainty splits.
% A Bayesian model still assigns weight to these possibilities through its prior assumptions.
% We make the concentration assumption explicit through Gamma factors in the Gaussian weight prior.
% The Gamma form is our modelling choice. It is not the only possible prior. A log normal for example would also work, as long at it is a density on the positive reals whose mode can be placed at an attainable total concentration and which has a second parameter for the spread.
% This Gamma prior supplies an assumption where the labels provide no preference. It does not add information from the labels.
% Each factor evaluates the total concentration produced at a training input, without using its label.
% Total concentration is a network output, not a separate sampled parameter.
% The Gamma mode states the preferred concentration. Its standard deviation describes the spread of that assumption.
% We place the mode above the number of classes because that is the range allowed by our evidence parameterisation.
% Combining this prior with the categorical likelihood gives the weight posterior.
% The prior supplies an assumption. It does not make concentration identifiable from single labels at fixed means.
% We can now examine the completed model's uncertainty decomposition.
\begin{frame}{Prior on Total Concentration}\label{frm:gamma-prior}
\begin{itemize}
\setlength{\itemsep}{3mm}
\item At fixed mean vectors, single labels \textbf{do not inform total concentration}.
\begin{itemize}
\item And therefore not the uncertainty allocation.
\end{itemize}
\item State the \textbf{total concentration assumption} through prior,
% Thesis eq:gamma-prior-weights.
\[
\tilde p(w)\propto p(w)\prod_{i=1}^{N}
\mathrm{Gamma}\bigl(\alpha_0(x_i;w)\mid\kappa,\beta\bigr).
\]
\begin{itemize}
\item Shape $\kappa>1$, rate $\beta>0$.
\item Prior mode $(\kappa-1)/\beta>C$ and standard deviation $\sqrt{\kappa}/\beta$. %mode states the preferred total concentration level and standard deviation describes the spread of that assumption.
\end{itemize}
\item Prior $\tilde p(w)$ and categorical likelihood give weight posterior,
% Thesis eq:edl-bnn-weight-posterior.
\[
p(w\mid D)\propto\tilde p(w)\prod_{i=1}^{N}m_{y_i}(x_i;w).
\]
\end{itemize}
\end{frame}
